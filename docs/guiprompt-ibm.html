Prompt

The Prompt dialog provides a place where you can select the appropriate values that are needed to construct a valid AS/400 command.

You can click Help to get more information about the command. To get a list of valid values for any field, click the question mark on the Help button and then click the field.

If you select values that require other entries or are related to other entries, additional fields are shown.

About parameters: Each field on the Prompt dialog corresponds to a parameter of the AS/400 command. A parameter is a value that is supplied to a command either as input or to control the actions of the command.

Available Function Keys

Several functions on the Prompt display are available from function keys as well as from the menu bar. Each function key is available only for commands to which it pertains. You can use the following function keys:
Key Function Menu Description
F1 Help Help Provides details about the command you are using.
F5 Reset View Resets all parameters to their original default values.
F9 All parameters View Shows all parameters that are available for the command.
F10 Advanced parameters View Shows the parameters that are not commonly used.
F11 Keyword View Shows the keyword for each parameter.
F12 Cancel File Closes this dialog without saving any changes you have made.
Shift+F2 Command String View Shows the command that results from the values that are currently entered.
