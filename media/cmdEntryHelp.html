CL Command Entry Reference

Use this page as an operational reference for CL Command Entry and Code Snippets.

Panel Overview

Command Input

  • Enter a CL command in the command input area and use Run to execute it.
  • Use Prompt or F4 to open the prompter.
  • You can also invoke prompting by placing ? before the command name.
  • Use F9 and F8 to step backward and forward through command history.
  • The clear button in the input field clears only the current input text.

Results and Message Log

  • Each command execution is added to the log with timestamp and elapsed time.
  • Messages are grouped by execution and can be collapsed or expanded.
  • The SEV selector filters displayed messages by minimum severity.
  • Use the toolbar menu to clear log content or clear stored history entries.

SQL Results Window

  • SQL statements open in a dedicated results window with sortable columns.
  • Use page controls to navigate loaded rows and fetch additional rows when available.
  • Use View SQL Stmt to display or hide the executed SQL statement.
  • Use Refresh in the results window to rerun the current SQL statement.

Code Snippets

  • Code Snippets provide reusable SQL statements for common tasks.
  • Built-in snippets are grouped by category and can be run directly.
  • User snippets can be created, edited, reordered, imported, and exported.
  • Snippet execution behavior for history and log retention follows Command Entry settings.
  • The Snippets tree view can be toggled from the Command Entry panel.

SQL Job Controls

  • The status area displays the current SQL job identifier.
  • Use the SQL job menu to copy the job ID or display joblog for that job.
  • Where supported, you can switch between shared and private SQL job modes.
  • Reconnect Server Job starts a new dedicated SQL server job for Command Entry.
